# Inventory Page Redesign Plan
## Retail POS - Enterprise-Grade UI

---

## Current State Analysis

**Technology Stack:**
- SvelteKit 2.x with Svelte 5 (runes: `$state`, `$derived`, `$effect`)
- CSS Custom Properties (no Tailwind)
- Lucide Svelte icons
- Custom components: Pagination, SearchableSelect
- Dark mode already implemented with CSS variables
- Backend: Go (Gin) + PostgreSQL

**Current Issues:**
- Table row layout lacks visual hierarchy
- No barcode copy functionality
- No filter chips for active filters
- Export UX basic (simple dropdown)
- No density control
- Stock badge only has "low" variant (needs medium/safe)
- Loading state basic spinner
- No column alignment standardization

---

## Redesign Objectives

1. **Speed & Efficiency:** Optimize for fast scanning by cashiers/admins
2. **Visual Clarity:** Reduce clutter, establish clear information hierarchy
3. **Scalability:** Handle hundreds to thousands of products
4. **Enterprise Quality:** Professional, modern, polished appearance
5. **UX Excellence:** Safe actions, helpful feedback, intuitive interactions

---

## Detailed Design Specifications

### 1. **Header Section**

```
┌─────────────────────────────────────────────────────────────┐
│  [Package Icon]  Manajemen Barang          [Tambah Produk+]│
└─────────────────────────────────────────────────────────────┘
```

- Keep existing structure but refresh styling
- Title: "Manajemen Barang" with Package icon (primary color)
- Primary button: "+ Tambah Produk" (rounded, primary color, icon + text)
- Add subtle shadow and hover lift effect to button

### 2. **Toolbar / Filter Bar**

**Layout:** Single integrated toolbar with grouped sections

```
┌─────────────────────────────────────────────────────────────────────┐
│  [Search:  "Cari produk, SKU, atau barcode..."   🔍] [▼ Kategori]│
│  [☐ Sembunyikan stok kosong]                    [Export ▾]        │
└─────────────────────────────────────────────────────────────────────┘
```

**Components:**

- **Search Bar:** 
  - Dominant, full-width when possible (min 300px, flex-grow)
  - Search icon inside (left padding)
  - Placeholder: "Cari produk, SKU, atau barcode..."
  - Debounced 250ms (already implemented)
  - Clear button (×) when text present
  - Character count hint: "Minimal 3 karakter" (warning tooltip)

- **Category Filter:**
  - Dropdown (SearchableSelect component reused)
  - Options: "Semua Kategori" + dynamic categories
  - Width: 220px

- **Stock Filter:**
  - Checkbox: "Sembunyikan stok kosong" (checked by default)
  - Position inline with other filters
  - Color: text-secondary

- **Export Control:**
  - Button with dropdown arrow: "Export ▾"
  - On click → shows dropdown menu (aligned right):
    - 📄 Export CSV
    - 📊 Export Excel
    - 📋 Export (Filtered Only) [if filters active]
  - Show loading spinner on button during export

### 3. **Filter Chips (Dynamic)**

Only show when filters are active (excluding default "hide empty stock").

```
┌─────────────────────────────────────────────────────────────────────┐
│  [Semua Kategori ✕]  [Stok > 0 ✕]                  [Clear All]    │
└─────────────────────────────────────────────────────────────────────┘
```

- Horizontal scrollable if many chips
- Each chip: rounded-pill, subtle background, close icon
- Click ✕ to remove individual filter
- "Clear All" link/button when multiple chips active
- Position: Immediately below toolbar, above table

### 4. **Table Redesign - Core Focus**

**Column Order:**
1. **Nama Produk** (primary data, left-aligned, bold)
2. **Stok** (right-aligned with badge visualization)
3. **Harga** (right-aligned, formatted)
4. **Kategori** (center/left, pill badge)
5. **Aksi** (kebab menu, right-aligned)

**Row Design - Rich Info Display:**

```
┌───────────────────────────────────────────────────────────────────┐
│ Turbo Mini 500g                                                    │
│ SKU: SKU-00001   📋  Barcode: 7622••••7521 📋                     │
│ ┌─────────────────────────────────────────────────────────────────┼
│ │ [Stock Badge]   Rp 15,000        [Kategori]   [⋮]              │
│ └─────────────────────────────────────────────────────────────────┘
│ █▓░░ Low (3)                       Elektronik                      │
└─────────────────────────────────────────────────────────────────────┘
```

**Detailed Row Structure (Multi-line):**

```
Line 1: [Product Name] (font-weight: 600, size: 1rem, color: text-primary)
Line 2: [SKU] • [Copy Icon]    [Barcode Truncated] • [Copy Icon]
         (font-size: 0.75rem, color: text-secondary)

Line 3: ────────────────────────────────────────────────────────────
         [Stock Badge]    [Harga (right)]    [Kategori Pill] [⋮]
```

**Stock Badge (Color-coded with threshold):**
- Low: stok < 5 → 🔴 red badge, text: "X Low" (e.g., "3 Low")
- Medium: 5 ≤ stok < 20 → 🟡 yellow/amber badge, text: "X" (just number)
- Safe: stok ≥ 20 → 🟢 green badge, text: "X" (just number)

Badge style: rounded-pill (99px), background with 10% opacity, text colored.

**Kategori Pill:**
- Primary color with 15% opacity background
- Text: category name (or "—" if none)
- Rounded-pill

**Action Column:**
- Kebab menu button (⋮) - vertical three dots
- Hover: background surface-hover
- Dropdown menu (right-aligned):
  - ✏️ Edit
  - 🗑️ Hapus (red danger text)
  - ℹ️ Lihat detail

### 5. **Row Interactions & States**

**Hover:**
- Row background: subtle highlight (rgba(primary, 0.05) or border-left accent)
- Smooth transition 150ms

**Loading State:**
- Skeleton table (shimmer effect)
- 5 skeleton rows loading
- Each row: gray pulsating blocks
- Reduce motion for accessibility

**Empty State:**
- Full-width centered content
- Icon: Package (or empty box)
- Text: "Tidak ada produk ditemukan"
- Subtext (if filters active): "Coba ubah filter atau tambah produk baru"
- Button (optional): "Tambah Produk" (if appropriate)

**Copy to Clipboard:**
- Click barcode or copy icon → copy full barcode (not truncated)
- Toast notification: "Barcode disimpan: 7622••••7521" or "Barcode disalin ✓"
- Toast auto-dismiss after 2s
- Position: bottom-center or near-top

### 6. **Export UX Enhancement**

**Dropdown Menu (absolute positioned):**

```
Export ▾
├─ 📄 Export CSV
├─ 📊 Export Excel
└─ 📋 Export (Filtered)   ← only when filters != default
```

- Positioned under button, right-aligned
- Dark background (bg-surface), border, shadow
- Hover effect on items
- Loading spinner replaces text during export
- On completion: toast "Export berhasil"

### 7. **Density Toggle (Optional Advanced)**

**Control:** Small toggle button in toolbar (left or right side)

```
[List Icon] / [Grid Icon] / [Compact Icon]
```

OR

```
[☐ Comfortable] / [☑ Compact]
```

**Variants:**
- **Comfortable (default):** Row height ~72px (includes multi-line spacing)
- **Compact:** Row height ~48px (single line: Name | Stock | Price | Kategori | Aksi)

Implementation: CSS variable `--row-density` on container → adjust paddings.

### 8. **Column Alignment**

- **Nama Produk:** left
- **Stok (with badge):** left/center (badge inside, badge text aligned)
- **Harga:** right (clean column, `text-align: right`, `font-variant-numeric: tabular-nums`)
- **Kategori:** left (pill centered)
- **Aksi:** right (kebab button)

### 9. **Responsive Behavior**

**Desktop (>1024px):** Full table, all columns visible

**Tablet (768-1024px):**
- Horizontal scroll for table (preserve headers)
- Nama Produk column min-width 200px
- Hide "Barcode subtext" but keep SKU visible (stack vertically)

**Mobile (<768px):**
- Stack to card layout (each product as card)
- OR hide non-essential columns: Barcode, maybe Category
- Keep: Name, Stock, Price, Actions

**Note:** Prioritize desktop-first (POS usage primarily desktop), but tablet-friendly.

**Spacing:**

- Row padding vertical: 16px
- Column gap: 16px
- Card border-radius: 12px (medium)

### 11. **Additional Enhancements**

- **Soft shadows:** Box-shadow for cards and dropdowns
- **Rounded corners:** Consistent across buttons, cards, badges
- **Sticky header:** Table header sticky on scroll
- **Smooth sorting:** Transition color on sort direction arrow
- **Accessibility:**
  - ARIA labels on icon buttons
  - Keyboard navigation for table
  - Focus states visible
  - Screen reader announcements for filter changes

## Edge Cases & Error Handling

- **Null barcode:** Show placeholder "—" (copy disabled)
- **No category:** Show "—" or "Tanpa Kategori"
- **Exported filtered empty:** Toast "Tidak ada data untuk diekspor"
- **Copy fails:** Fallback, show error toast
- **Slow API:** Keep skeleton until timeout (10s max)
- **500 errors:** Show error state with retry button

## Accessibility

- Table headers have `scope="col"`
- Buttons have `aria-label` (e.g., "Edit product Turbo Mini")
- Kebab menu has `aria-haspopup="true"`, `aria-expanded`
- Toast has `role="status"`, `aria-live="polite"`
- Keyboard: Tab/Shift+Tab through interactive elements
- Escape closes dropdowns/modals
- Focus visible outline (offset)
