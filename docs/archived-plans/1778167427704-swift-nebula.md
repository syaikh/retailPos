## Performance Optimization Considerations

### Current Bottlenecks
- **Sequential inserts**: Each transaction inserted one at a time (slow)
- **Sequential invoice numbers**: `INV-2024-000001` format not concurrent-safe
- **No batching**: Each insert is a separate database round-trip

### Recommended Optimization Strategy

#### Option 1: Batch Inserts (Recommended - Simpler)
- Use COPY or batch INSERT with tx.ExecBatch
- batchSize = 1000
- Expected speedup: 3-5x faster

#### Option 2: Worker Pool with UUID Invoices
- numWorkers = 4, batchSize = 1000
- Change invoice format for concurrency safety:
  - `invoice := fmt.Sprintf("INV-%s", uuid.New().String()[:8])`
  - Results: INV-a1b2c3d4
- Workers process separate day ranges or product batches
- Expected speedup: 5-10x faster
