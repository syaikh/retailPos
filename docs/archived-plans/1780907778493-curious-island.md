# Plan: Improve Audit Logs Activity Table

## Goal
Make the activity log table in `AuditLogs.svelte` look more polished and visually consistent with the rest of the admin panel (Users, Categories pages).

## Current Issues
1. Table rows are plain — no visual grouping or icon cues for entity types
2. Action badges use `Badge` component but could be more visually distinct with icons
3. Resource/entity column uses a plain `<code>` block — no icon or color
4. Timestamp column is small text with a tiny icon — could be more readable
5. Description column uses `truncate` which clips potentially useful info
6. The "View Details" button only shows on hover (`opacity-0 group-hover:opacity-100`) — reduces discoverability
7. Table header uses `bg-bg-secondary` but other pages use `shadow-sm` on their sticky headers
8. No row hover indicator beyond subtle background change
9. The overall table feels flat compared to the card-based layout of other admin pages

## Changes

### 1. Add entity type icons to table rows
- Import entity-specific icons (Package, ShoppingCart, Users, Shield, Tag, Store, LogIn)
- Show a small icon badge next to the entity_type text in the Resource column, matching the filter chips above
- This gives quick visual scanning ability

### 2. Enhance Action badges with icons
- Instead of just `<Badge>CREATE</Badge>`, show `<Badge><Plus size={10} />CREATE</Badge>` with the matching icon from the filter definitions
- Makes actions scannable at a glance

### 3. Improve Timestamp column
- Show date and time on separate lines (date larger, time smaller/muted)
- Use a slightly wider column to accommodate
- Keep the calendar icon but make it part of a small icon container

### 4. Improve Actor column
- Add a small avatar circle with the user's first letter (like Users page does with gradient-bg-primary)
- This is consistent with the Users page pattern

### 5. Improve Description column
- Remove `truncate` class, allow text to wrap to 2 lines with `line-clamp-2`
- Slightly increase max-width so descriptions breathe

### 6. Make the Details button always visible
- Remove `opacity-0 group-hover:opacity-100`
- Use a subtle always-visible style: `text-text-muted/60 hover:text-primary-light`
- Improves discoverability

### 7. Polish table header
- Add `shadow-sm` to sticky thead (consistent with Users.svelte, Categories.svelte)
- Slightly increase header padding for breathing room

### 8. Add subtle row striping or left-border accent
- Add a left border accent on hover using `border-l-2 border-l-primary-light/50` on hover rows
- This gives a nice interactive feel consistent with the dark theme

### 9. Improve empty state
- Match the pattern from Users.svelte: use `empty-state-icon` class with a larger icon container
- Add a slightly more descriptive message

### 10. Improve loading skeleton
- Match the column structure more closely to the actual table
- Add a skeleton circle for the actor avatar column

## Files to Modify
- `web/src/lib/pages/admin/AuditLogs.svelte` — table section only (lines ~373-463), plus minor import additions

## What NOT to change
- Filter toolbar (already well-designed)
- Details drawer (already polished)
- Custom date modal (already fine)
- Data fetching logic
- Pagination component
