# Plan: Redesign Inventory Page - Product Management

## Overview
Redesign the inventory page into a modern, enterprise-grade UI with focus on speed, clarity, and usability. The existing codebase is a SvelteKit project with Tailwind CSS 4.x.

## Technology Stack
- **Framework**: SvelteKit
- **Styling**: Tailwind CSS 4.x with custom theme tokens
- **Icons**: lucide-svelte
- **State**: Svelte stores

## Additional Requirements (from user feedback)

### Requirement 1: Language
- All UI text must be in **Bahasa Indonesia**
- This includes headers, buttons, placeholders, labels, error messages, toasts, etc.

### Requirement 2: Large Category List Handling (Best Practice)
Given that 50 was a random number, implement a scalable solution:

**Best Practice Approach:**
1. **Fixed max-height with overflow scroll** - Set `.options-list { max-height: 280px; overflow-y: auto }`
   - This provides native scrollbar without rendering all items
   - Works well for up to ~500 items

2. **Search-first UX** - Always encourage users to search/filter before scrolling
   - Keep search box prominent at top of dropdown
   - Search results update in real-time (no submit needed)

3. **Keyboard navigation** - Enable Arrow Up/Down, Enter to select
   - Critical for power users scanning through lists

4. **Optional enhancement** - Only if needed for 500+ items:
   - Virtual scrolling (render only visible items)
   - Pagination within dropdown (Load More button)

The current SearchableSelect already has search functionality - just need to add max-height scroll and keyboard nav.

## Implementation Steps

### Step 1: Update Theme System (app.postcss)
Enhance the existing theme tokens to support the new design requirements:
- Add `--color-primary: #6366f1` (indigo-500)
- Add `--color-success: #10b981` (emerald-500)
- Add `--color-danger: #ef4444` (red-500)
- Add `--color-warning: #f59e0b` (amber-500)
- Stock level colors:
  - `stock-danger`: Low stock (stock < 5) - Red
  - `stock-warning`: Medium stock (5-19) - Yellow
  - `stock-success`: Safe stock (≥20) - Green
- Add rounded corners token: `radius-md: 8px`
- Add spacing scale

### Step 2: Create new UI Components
Create reusable components in `src/lib/components/ui/`:

#### 2.1 StockBadge.svelte
- Props: `level: 'rendah' | 'sedang' | 'aman'`, `value: number`
- Logic:
  - RENDAH (red): stock < 5
  - SEDANG (yellow): 5 ≤ stock < 20
  - AMAN (green): stock ≥ 20

#### 2.2 KebabMenu.svelte
- Props: `items: { label, icon?, variant?, action }[]`
- Dropdown with vertical dots icon (⋮)
- Menu items with Edit (primary), Delete (danger), Lihat Detail

#### 2.3 FilterChip.svelte
- Props: `label`, `onRemove`
- Displays active filter with ✕ button

#### 2.4 SkeletonTable.svelte
- Array of column widths
- Animated skeleton rows for loading state

#### 2.5 DensityToggle.svelte
- Options: Compact / Comfortable
- Updates table row padding

### Step 3: API Enhancements (productApi.ts)
Add optional parameter to include `updated_at` in product fetch:
- `getAll(limit, offset, includeUpdated = false)`

### Step 4: Rewrite Inventory Page
Transform `web/src/routes/(app)/inventory/+page.svelte`:

#### 4.1 Header Section
- Title: "Manajemen Produk" (left-aligned)
- Primary button: "+ Tambah Produk" (right-aligned, primary color)

#### 4.2 Toolbar Section
- **Search Bar** (dominant, ~400px):
  - Placeholder: "Cari produk, SKU, atau barcode..."
  - Debounced (150ms) for fast scanning
- **Filter Dropdowns**:
  - Kategori (dropdown with searchable/filterable list, with scrolling for 50+ items)
  - Stok (Semua / Rendah / Habis)
- **Export Dropdown**:
  - Export CSV, Export Excel, Export Tersaring

#### 4.3 Active Filter Chips
- Display above table when filters active
- Chips: [Semua Kategori ✕], [Stok > 0 ✕]
- Click ✕ to remove filter

#### 4.4 Table Redesign
**Column Order:**
1. Nama Produk (primary column, bold, 25%)
2. Stok (right-aligned, 15%)
3. Harga (right-aligned, 15%)
4. Kategori (15%)
5. Terakhir Diperbarui (15%)
6. Aksi (15%, kebab menu)

**Row Structure:**
```
┌────────────────────────────────────────────────┐
│ Product Name (bold, large)                    │
│ SKU: SKU-00001 📋 • 7622••••7521 📋          │
└────────────────────────────────────────────────
```

- **Product Name**: Bold, larger font (text-lg)
- **Secondary info**: SKU + copy button, Barcode (truncated with •••) + copy button
- Copy icons use clipboard API with toast feedback
- Barcode truncation: First 4 digits + "••••" + Last 4 digits

#### 4.5 Stock Badges
Use colored badges in Stok column:
- `[3 Rendah]` (red bg/text)
- `[15 Sedang]` (yellow bg/text)
- `[50 Aman]` (green bg/text)

#### 4.6 Actions Menu (Kebab)
- Edit (opens modal)
- Delete (danger, with confirmation)
- Lihat Detail (opens detail drawer/modal)

#### 4.7 Interactions
- Row hover: subtle highlight (bg-white/5)
- Copy barcode/SKU → toast: "Barcode disalin" / "SKU disalin"

#### 4.8 Advanced Features (Optional)
