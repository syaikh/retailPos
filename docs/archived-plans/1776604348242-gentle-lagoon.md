# Plan: Implement Inventory Export with Date Range Filter

## Overview
Add GET `/api/inventory/export` endpoint with CSV & Excel export support, filtering by date range (`created_at`), with proper layering (handler → service → repository), validation, permission check, streaming for large datasets, and unit tests.

---

## 1. Architecture & Layering

### Handler (`internal/handler/handlers.go`)
- **Method**: `ExportInventory(c *gin.Context)`
- **Permission**: Requires `product:export` (admin only)
- Responsibilities:
  - Parse `start_date` and `end_date` query parameters
  - Validate date format (`2006-01-02`) and logical order (`start_date <= end_date`)
  - Parse `format` query param (csv|xlsx, default: csv)
  - Call service layer
  - Set response headers for CSV/Excel download
  - Stream response row-by-row for large datasets

### Service (`internal/service/inventory_service.go`) - NEW FILE
- **Methods**:
  - `ExportInventoryCSV(ctx context.Context, startDate, endDate *time.Time) (io.Reader, error)`
  - `ExportInventoryExcel(ctx context.Context, startDate, endDate *time.Time) (io.Reader, error)`
- Responsibilities:
  - Accept optional `*time.Time` parameters (nil = no filter)
  - Call repository
  - Stream CSV/Excel rows directly to output stream (no full in-memory build)
  - Return `io.Reader` for streaming

### Repository (`internal/repo/product_repo.go`)
- **Method**: `GetAllForExport(ctx context.Context, startDate, endDate *time.Time) (chan model.Product, error)`
- Responsibilities:
  - Build dynamic SQL with optional `WHERE created_at BETWEEN $1 AND $2`
  - Use prepared statements with context
  - Return channel for streaming rows (no full slice in memory)

### Model
- Reuse existing `model.Product` (already contains all required fields)

## 2. Detailed Implementation

### 2.1 Repository Layer

**File**: `internal/repo/product_repo.go`

Add new method using channel-based streaming:

```go
func (r *ProductRepo) GetAllForExport(ctx context.Context, startDate, endDate *time.Time) (<-chan model.Product, error) {
    query := `SELECT id, name, sku, barcode, price, stock, group_id, created_at, updated_at, deleted_at, restored_at 
              FROM products 
              WHERE deleted_at IS NULL`
    args := []any{}
    placeholderIdx := 1

    if startDate != nil && endDate != nil {
        query += fmt.Sprintf(" AND DATE(created_at) BETWEEN $%d::date AND $%d::date", placeholderIdx, placeholderIdx+1)
        args = append(args, startDate.Format("2006-01-02"), endDate.Format("2006-01-02"))
    }

    query += " ORDER BY created_at ASC"

    rows, err := r.db.QueryContext(ctx, query, args...)
    if err != nil {
        return nil, err
    }

    productChan := make(chan model.Product, 100) // buffered channel

    go func() {
        defer rows.Close()
        defer close(productChan)
        for rows.Next() {
            var p model.Product
            if err := rows.Scan(&p.ID, &p.Name, &p.SKU, &p.Barcode, &p.Price, &p.Stock, &p.GroupID, &p.CreatedAt, &p.UpdatedAt, &p.DeletedAt, &p.RestoredAt); err != nil {
                continue
            }
            select {
            case productChan <- p:
            case <-ctx.Done():
                return
            }
        }
    }()

    return productChan, nil
}
```

```go
package service

import (
    "bytes"
    "context"
    "encoding/csv"
    "fmt"
    "io"
    "strings"
    "time"

    "github.com/xuri/excelize/v2"

    model "retailPos/internal/model"
    "retailPos/internal/repo"
)

type InventoryService struct {
    productRepo *repo.ProductRepo
}

func NewInventoryService(productRepo *repo.ProductRepo) *InventoryService {
    return &InventoryService{
        productRepo: productRepo,
    }
}

// ExportInventoryCSV streams CSV directly to writer (no full buffering)
func (s *InventoryService) ExportInventoryCSV(ctx context.Context, w io.Writer, startDate, endDate *time.Time) error {
    products, err := s.productRepo.GetAllForExport(ctx, startDate, endDate)
    if err != nil {
        return err
    }

    writer := csv.NewWriter(w)
    defer writer.Flush()

    // Header
    writer.Write([]string{"product_id", "product_name", "sku", "stock", "price", "created_at"})

    // Rows - stream from channel
    for p := range products {
        record := []string{
            fmt.Sprintf("%d", p.ID),
            p.Name,
            p.SKU,
            fmt.Sprintf("%d", p.Stock),
            fmt.Sprintf("%d", p.Price),
            p.CreatedAt.Format("2006-01-02 15:04:05"),
        }
        if err := writer.Write(record); err != nil {
            return err
        }
        writer.Flush() // Stream each row
    }

    return nil
}

// ExportInventoryExcel generates Excel file in memory and returns reader
func (s *InventoryService) ExportInventoryExcel(ctx context.Context, startDate, endDate *time.Time) (io.Reader, error) {
    products, err := s.productRepo.GetAllForExport(ctx, startDate, endDate)
    if err != nil {
        return nil, err
    }

    f := excelize.NewFile()
    sheet := "Inventory"
    f.NewSheet(sheet)

    // Header
    headers := []string{"product_id", "product_name", "sku", "stock", "price", "created_at"}
    for i, h := range headers {
        f.SetCellValue(sheet, cellAt(i+1, 1), h)
    }

    // Rows
    rowNum := 2
    for p := range products {
        f.SetCellValue(sheet, cellAt(1, rowNum), p.ID)
        f.SetCellValue(sheet, cellAt(2, rowNum), p.Name)
        f.SetCellValue(sheet, cellAt(3, rowNum), p.SKU)
        f.SetCellValue(sheet, cellAt(4, rowNum), p.Stock)
        f.SetCellValue(sheet, cellAt(5, rowNum), p.Price)
        f.SetCellValue(sheet, cellAt(6, rowNum), p.CreatedAt.Format("2006-01-02 15:04:05"))
        rowNum++
    }

    // Save to buffer
    var buf bytes.Buffer
    if err := f.Write(&buf); err != nil {
        return nil, err
    }

    return &buf, nil
}

// Helper untuk cell address Excel (A1, B1, etc.)
func cellAt(col, row int) string {
    return fmt.Sprintf("%s%d", string(rune('A'+col-1)), row)
}
```

## 11. Implementation Decisions

**Permission Seeding (Q1)**
- New migration: `migrations/0007_seed_inventory_export_permission.sql`
- Content: `INSERT INTO permissions (code, description, category) VALUES ('inventory:product:export', 'Export inventory data', 'inventory') ON CONFLICT DO NOTHING;`
- Admin automatically receives this via existing cross-join (migration 0004).

**Frontend Conditional Visibility (Q2)**
- **Recommendation**: Show export button only to admin users using the existing `$user` store.
- Implementation: `import { user } from '$lib/stores.js';` then `{#if $user?.role === 'admin'}` around export controls.
- Rationale: Cleaner UX, reduces unauthorized attempts. Backend still enforces permission as source of truth.

**Excel Streaming Strategy (Q3)**
- **Recommendation**: Keep in-memory `bytes.Buffer` for Excel generation.
- Rationale: Typical inventory < 10k rows produces ~5-10MB file, acceptable for server memory. Streaming Excel to response is complex with `excelize` and offers diminishing returns. If needed later, implement async export job for very large datasets.

**Date Filtering Boundaries (Q4)**
- Use `DATE(created_at)` in SQL to ignore time component:
  ```sql
  WHERE deleted_at IS NULL
    AND DATE(created_at) BETWEEN $1::date AND $2::date
  ```
- Handler passes parsed dates (midnight 00:00:00) — no need to adjust to end-of-day.
- Guarantees inclusive full-day coverage.

```svelte
async function exportInventory() {
  if (!exportStartDate || !exportEndDate) {
    alert('Pilih tanggal awal dan akhir');
    return;
  }
  exportLoading = true;
  try {
    const token = localStorage.getItem('token'); // or from cookie/store
    const url = `/api/inventory/export?start_date=${exportStartDate}&end_date=${exportEndDate}&format=${exportFormat}`;
    const resp = await fetch(url, {
      headers: { Authorization: `Bearer ${token}` }
    });
    if (!resp.ok) throw new Error(await resp.text());
    const blob = await resp.blob();
    const downloadUrl = window.URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = downloadUrl;
    a.download = `inventory_${exportStartDate}_to_${exportEndDate}.${exportFormat}`;
    document.body.appendChild(a);
    a.click();
    a.remove();
    window.URL.revokeObjectURL(downloadUrl);
  } catch (e) {
    alert('Export gagal: ' + e.message);
  } finally {
    exportLoading = false;
  }
}
```

## 13. Final Notes

- Permission `inventory:product:export` **needs to be seeded**. A new migration file `migrations/0007_seed_inventory_export_permission.sql` will be created to insert this permission.
- Admin role already has all permissions via cross-join in migration 0004, so once the permission row exists, admin automatically gets it.
- Handler permission check uses `h.hasPermission(c, "inventory:product:export")` which reads user permissions from context (populated by auth middleware).
- For non-admin users, the export button should be hidden in frontend (UX) AND backend still enforces permission.
- Streaming: Each channel send blocks if buffer full, providing natural backpressure; Gin writes to client incrementally.
- Date filtering: Repository uses `BETWEEN $1 AND $2` which is **inclusive** of both boundaries. For date-only parameters, this means `created_at >= start_date 00:00:00 AND created_at <= end_date 23:59:59` when dates are passed as midnight. The handler passes raw `time.Time` values which include time component; for proper full-day coverage, the handler should set times to start-of-day and end-of-day (23:59:59) or rely on date-only comparison in SQL (`DATE(created_at) BETWEEN $1::date AND $2::date`). Recommended approach: use `DATE(created_at)` cast in SQL to avoid time component issues.
