# Optimization Plan: Vite Bundle Size untuk RetailPOS

## Analisis Masalah

### Dependencies Besar yang Ditemukan:
| Library | Ukuran Estimate | Lokasi Import |
|---------|----------------|---------------|
| `xlsx` | ~500KB+ | reports/+page.svelte |
| `jspdf` | ~400KB | reports/+page.svelte |
| `chart.js/auto` | ~200KB | reports/+page.svelte |
| `jspdf-autotable` | ~100KB | reports/+page.svelte |
| `lucide-svelte` | ~50KB | multiple places |

### Penyebab Chunk Besar:
1. **Import synchronis** - Semua library berat di-load saat halaman pertama kali terbuka
2. **Tidak ada code splitting** - Tidak ada konfigurasi manual chunks di vite.config.js
3. **Penggunaan `chart.js/auto`** - Mengimport seluruh library, bukan module spesifik
4. **Penggunaan `* as XLSX`** - Mengimport semua fitur XLSX, bukan hanya yang diperlukan
5. **Tidak ada lazy loading** - Routes dan komponen berat di-load sekaligus

---

## Rencana Implementasi

### 1. Konfigurasi `vite.config.js` dengan Manual Chunks

Buat konfigurasi yang memisahkan:
- `vendor` - SvelteKit core
- `ui-libs` - lucide-svelte, date-picker-svelte
- `heavy-libs` - chart.js, jspdf, xlsx (lazy loaded)

### 2. Dynamic Import di Reports Page

Ganti import synchronis dengan dynamic import:

```javascript
// SEBELUM
import Chart from 'chart.js/auto';
import jsPDF from 'jspdf';
import * as XLSX from 'xlsx';

// SESUDAH - Dynamic import di dalam fungsi
async function exportPDF() {
  const [{ default: jsPDF }, { default: autoTable }] = await Promise.all([
    import('jspdf'),
    import('jspdf-autotable')
  ]);
  // ... use jsPDF
}

async function exportExcel() {
  const XLSX = await import('xlsx');
  // ... use XLSX
}

async function initChart() {
  const Chart = (await import('chart.js/auto')).default;
  // ... use Chart
}
```

### 3. Route-based Code Splitting

Gunakan fasilitas SvelteKit untuk preloading:
- `data-sveltekit-preload-data` untuk prefetch data
- `data-sveltekit-preload-code` untuk prefetch code (hanya saat hover)

### 4. Install Bundle Visualizer

Tambahkan `rollup-plugin-visualizer` untuk analisis.
