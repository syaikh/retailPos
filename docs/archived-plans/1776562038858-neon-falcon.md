# Plan: Fungsikan Tombol Ekspor PDF/Excel pada Halaman Report

## Goal
Mengaktifkan tombol "Ekspor PDF/Excel" di `/web/src/routes/(app)/reports/+page.svelte` agar dapat mengexport data laporan penjualan (chart + tabel transaksi) ke format PDF dan Excel.

## Requirements
- **Export PDF**: Chart sebagai gambar + Tabel Transaksi
- **Export Excel**: Tabel Transaksi (bisa include chart sebagai gambar)
- **Library**: jsPDF + xlsx (client-side)

## Steps

### 1. Install Dependencies
Install library yang diperlukan:
```
npm install jspdf jspdf-autotable xlsx
```

### 2. Tambahkan Import di `reports/+page.svelte`
Tambahkan import untuk library:
```javascript
import jsPDF from 'jspdf';
import 'jspdf-autotable';
import * as XLSX from 'xlsx';
```

### 3. Buat Fungsi Export PDF
- Ambil chart canvas sebagai gambar (menggunakan `canvas.toDataURL()`)
- Tambahkan judul laporan dengan tanggal range
- Sisipkan gambar chart
- Tambahkan tabel transaksi menggunakan autotable
- Generate dan download PDF

### 4. Buat Fungsi Export Excel
- Ambil data transaksi dari state `transactions`
- Buat worksheet dengan data tabel
- Generate dan download file `.xlsx`

### 5. Modifikasi Tombol Export
Tambahkan dropdown atau toggle untuk memilih format PDF/Excel:
- Ubah button menjadi split button atau dropdown
- options: "Ekspor PDF" dan "Ekspor Excel"

### 6. Styling
Tambahkan styling untuk dropdown menu jika diperlukan.
