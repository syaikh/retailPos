# UI/UX Improvements for Reports Page - Two-Column Smart Date Range Picker

## Overview
This plan outlines the implementation of a comprehensive two-column date range picker with smart adaptive selectors for the Retail POS Reports page. The implementation is timezone-aware (GMT+07/WIB), uses Svelte 5 Runes syntax, and maintains the dark minimal theme with purple/emerald accents.

## Architecture

### Component Structure
```
ReportsPage.svelte
├── PeriodSelector.svelte (new - two-column adaptive selector)
│   ├── PeriodLeftMenu.svelte (left column - period options)
│   └── PeriodRightSelector.svelte (right column - adaptive selector)
├── StatCard.svelte (refactored - adaptive card component)
└── usePeriodState.js (composable for state management)
```

## Implementation Details

### 1. Timezone Marker Display

**Location:** Header section above date range

**Format:** `{dayCount} hari sebelumnya. {startDate} - {endDate} (GMT+07)`

**Implementation:**
```svelte
<div class="text-xs text-text-muted mt-1">
  {totalDays} hari sebelumnya. {formatDateDisplay(startDate)} - {formatDateDisplay(endDate)} (GMT+07)
</div>
```

### 2. Svelte 5 State Management

```javascript
// State using Svelte 5 Runes
let selectedPeriodType = $state('7days'); // 'realtime' | 'yesterday' | '7days' | '30days' | 'weekly' | 'monthly' | 'yearly'
let dateRange = $state({ start: '', end: '' });
let chartType = $state('line');
let userOverriddenTab = $state(false);
let activeTab = $state('daily');

// Derived values
const autoTab = $derived.by(() => {
  if (userOverriddenTab) return activeTab;
  const days = calculateDaysBetween(dateRange.start, dateRange.end);
  if (days <= 30) return 'daily';
  if (days <= 180) return 'weekly';
  return 'monthly';
});

const autoChartType = $derived.by(() => {
  return selectedPeriodType === 'realtime' || selectedPeriodType === 'yesterday' 
    ? 'hourly' 
    : (autoTab === 'daily' ? 'line' : 'bar');
});

// Effect for auto-updating
$effect(() => {
  dateRange; // reactive dependency
  if (!userOverriddenTab) {
    activeTab = autoTab;
  }
});
```

### 3. Two-Column Adaptive Selector

#### Left Column Options:
- **Real-time** - Shows current day hourly data
- **Kemarin** - Shows yesterday hourly comparison  
- **7 Hari** - Fixed 7-day period (excludes today)
- **30 Hari Sebelumnya** - Fixed 30-day period (excludes today)
- **Per Minggu** - Week selector with snap-to-week
- **Per Bulan** - Month dropdown grid
- **Berdasarkan Tahun** - Year dropdown grid

#### Right Column Adaptive Content:

| Selection | Right Column Display |
|-----------|---------------------|
| Real-time | `Hari Ini - Pk 06:00` (static text) |
| Kemarin | `23-05-2026` (static date) |
| 7 Hari | `17-05-2026 - 23-05-2026` (excludes today) |
| 30 Hari | `23-04-2026 - 23-05-2026` (excludes today) |
| Per Minggu | Monthly calendar with snap-to-week hover selection |
| Per Bulan | Grid dropdown of month names (Jan, Feb, Mar...) |
| Berdasarkan Tahun | Grid dropdown of years (2024, 2025, 2026...) |

### 4. Backend Integration

**New Endpoint Pattern:**
```
GET /api/dashboard/chart/{type}?period={selectedPeriodType}&date={referenceDate}
```

**Period Type Mapping:**
- `realtime` → hourly aggregation
- `yesterday` → hourly aggregation for yesterday
- `7days` → daily aggregation, excludes today
- `30days` → daily aggregation, excludes today  
- `weekly` → weekly aggregation, snap-to-week
- `monthly` → monthly aggregation
- `yearly` → yearly aggregation

### 6. Auto-Switch Logic

```javascript
function updatePeriodType(newType) {
  selectedPeriodType = newType;
  userOverriddenTab = true;
  
  // Set date range based on type using Jakarta timezone
  const today = getTodayInJakarta();
  const daysAgo = getDateNDaysAgoInJakarta;
  
  switch (newType) {
    case 'realtime':
      // Current day, hourly
      dateRange = { start: today, end: today };
      chartType = 'hourly';
      break;
    case 'yesterday':
      const yesterday = daysAgo(1);
      dateRange = { start: yesterday, end: yesterday };
      chartType = 'hourly';
      break;
    case '7days':
      // Exclude today - last 7 complete days
      dateRange = { start: daysAgo(8), end: daysAgo(1) };
      break;
    case '30days':
      // Exclude today - last 30 complete days  
      dateRange = { start: daysAgo(31), end: daysAgo(1) };
      break;
    case 'weekly':
    case 'monthly':
    case 'yearly':
      // Use default tab-based ranges
      break;
  }
  
  fetchSales();
}
```

### 8. Backend API Requirements

**New Endpoint:** `GET /api/dashboard/chart/hourly`
- Parameters: `date` (YYYY-MM-DD)
- Returns: hourly aggregation data for 24-hour period

**Updated Periods Endpoint:** `GET /api/dashboard/comparison`
- Accept `period` parameter: `hourly` | `daily` | `weekly` | `monthly` | `yearly`
- Return appropriate comparison period metadata
