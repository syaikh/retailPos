# Implementation Plan: Full Database-Driven RBAC — Final Sprint Plan

**Goal:** Replace all hardcoded role checks with a dynamic, database-driven permission system supporting granular permissions, full admin UI for role & user management, and production-grade testing.

**Approach:** Two sprints with gradual rollout
- **Sprint 1** (2 weeks): Backend RBAC + frontend integration → production ready (no admin UI)
- **Sprint 2** (1 week): Admin UI for managing roles & users

**Estimated Total Effort:** 53-70 hours (Sprint 1: 43-56h + Sprint 2: 28-36h with testing)

**Risk Level:** Medium (DB migration + JWT breaking change, but gradual rollout mitigates)

```sql
    name VARCHAR(50) UNIQUE NOT NULL,
    description TEXT,
    is_system BOOLEAN DEFAULT FALSE,  -- true for admin/cashier (protected)
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()

    id SERIAL PRIMARY KEY,
    code VARCHAR(100) UNIQUE NOT NULL,
    description TEXT NOT NULL,

);

CREATE TABLE role_permissions (
    role_id INT NOT NULL REFERENCES roles(id) ON DELETE CASCADE,
    permission_id INT NOT NULL REFERENCES permissions(id) ON DELETE CASCADE,
    PRIMARY KEY (role_id, permission_id)
);

```

   ```go
   // NEW: ValidateAccessToken(token) -> (userID int, roleID int, roleName string, err)
   func (s *jwtTokenService) ValidateAccessToken(tokenString string) (int, int, string, error) {
       token, _ := jwt.Parse(...)
       claims := token.Claims.(jwt.MapClaims)
       userID := int(claims["user_id"].(float64))
       roleName, _ := claims["role"].(string)
       roleID := int(claims["role_id"].(float64))  // newly added claim
       return userID, roleID, roleName, nil
   }
   ```

    ```go
        // Only admin can create roles
        if c.GetString("role") != "admin" {
            c.JSON(403, gin.H{"error": "Admin only"})
            return
        }

            Permissions []int  `json:"permission_ids"` // array of permission IDs
    ```

    ```go
        // Only admin
        if c.GetString("role") != "admin" {
            c.JSON(403, gin.H{"error": "Admin only"})
            return
        }
        userID := c.Param("id")
        var input struct { RoleID int `json:"role_id" binding:"required"` }
        if err := c.ShouldBindJSON(&input); err != nil { ... }

        // Prevent editing other admins (unless you are superadmin - not implemented yet)
        targetUser, _ := h.userRepo.GetByID(parseInt(userID))
        if targetUser == nil { c.JSON(404, ...); return }
        targetRole, _ := h.roleRepo.GetRoleByID(targetUser.RoleID)
        if targetRole.Name == "admin" {
            c.JSON(403, gin.H{"error": "Cannot modify admin users"})
            return
        }

        // Validate role exists
        role, _ := h.roleRepo.GetRoleByID(input.RoleID)
        if role == nil { c.JSON(404, ...); return }

        // Update
        if err := h.roleRepo.UpdateUserRole(parseInt(userID), input.RoleID); err != nil { ... }
        c.JSON(200, gin.H{"message": "Role updated"})
    }
    ```

## Critical: Breaking Changes & Compatibility

### JWT Token Breaking Change

**Before:** `ValidateAccessToken(token) → (userID int, role string, err)`
**After:** `ValidateAccessToken(token) → (userID int, roleID int, roleName string, err)`

**Impact:** Any Go code calling `ValidateAccessToken` must update to 4 return values.

**Call sites to update:**
1. `internal/auth/middleware.go:AuthMiddleware` — main user
2. `internal/handler/handlers.go:RefreshToken` — uses `ValidateRefreshToken` only, not affected
3. Any future code — search: `ValidateAccessToken(`
