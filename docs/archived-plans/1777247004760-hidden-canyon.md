# Rollback to Last Commit Plan

## Objective
Rollback to the last commit and discard any new uncommitted files (both changes to tracked files and untracked files).

## Steps

1. **Verify Current State** (Optional but recommended)
   - Run `git status` to see the current state of the working directory and staging area.
   - This helps confirm what changes will be discarded.

2. **Discard Changes in Tracked Files**
   - Run `git reset --hard HEAD` to reset all tracked files to the state of the last commit.
   - This will discard any staged or unstaged changes to tracked files.

3. **Remove Untracked Files**
   - Run `git clean -f` to remove untracked files from the working directory.
   - Note: This does not remove untracked directories by default. To also remove untracked directories, use `git clean -fd`.
   - Warning: `git clean` operations are permanent and cannot be undone. Ensure you do not have any important untracked files you wish to keep.

4. **Verify Rollback**
   - Run `git status` again to confirm that the working directory is clean and matches the last commit.

## Safety Considerations
- The `git reset --hard HEAD` command will discard all changes to tracked files since the last commit. This action cannot be undone.
- The `git clean -f` command will permanently delete untracked files. Use with caution.
- Consider backing up any important untracked files before running the clean command if unsure.

## Expected Outcome
After executing these steps, the working directory will match exactly the state of the last commit, with no staged changes, unstaged changes, or untracked files remaining.
