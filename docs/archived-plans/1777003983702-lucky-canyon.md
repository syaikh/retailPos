# Redesign Tombol "Bayar Sekarang" pada Laman POS

## Tujuan
Memperedesain tombol "Bayar Sekarang" pada halaman POS dengan styling yang sama seperti tombol ekspor di laman inventory, sesuai permintaan pengguna.

## Spesifikasi Desain (Diperbarui berdasarkan feedback pengguna)
1. **Visual Style**:
   - Sama dengan tombol ekspor di laman inventory (background: var(--success) = #10b981)
   - Warna teks putih (#FFFFFF)
   - Kontras tinggi terhadap latar belakang gelap (dark mode navy/charcoal)
   - Elemen utama (Call to Action)

2. **Atribut Elemen**:
   - Padding: 12px 24px (sesuai tombol ekspor inventory)
   - Border Radius: 6px (sesuai tombol ekspor inventory)
   - Typography: Font Sans Serif (Inter atau Roboto), Semi-Bold/Bold (font-weight: 800), Uppercase, warna teks #FFFFFF
   - Iconography: Ikon keranjang belanja di sisi kiri teks
   - Effects: Tidak ada glow berlebihan, hanya perubahan warna subtil untuk tactile feedback

3. **State Interaction**:
   - Default: Background var(--success) (#10b981)
   - Hover State: Background menjadi sedikit lebih gelap (#059669)
   - Pressed State: Background menjadi lebih gelap lagi (#047857)
   - Penting: Tidak ada perubahan ukuran (scale/translate) yang dapat menyebabkan layout flicker

## Implementasi yang Telah Dilakukan

### 1. Modifikasi Komponen Button (src/lib/components/ui/Button.svelte)
- Tambahkan prop `icon` opsional untuk menyimpan ikon (Svelte component/snippet)
- Render ikon sebelum children jika prop `icon` diberikan
- Pastikan perubahan ini kompatibel mundur (icon default null)

### 2. Update CheckoutPanel.svelte (src/lib/components/pos/CheckoutPanel.svelte)
- Import ikon ShoppingCart dari lucide-svelte
- Tambahkan prop `icon` ke komponen Button dengan nilai ikon ShoppingCart
- Gaya tombol disesuaikan dengan tombol ekspor inventory:
  - Menggunakan variabel CSS var(--success) untuk background
  - Padding 12px 24px
  - Border radius 6px
  - Font weight 800, uppercase
  - Hover state: background berubah menjadi #059669 (darker emerald)
  - Active state: background berubah menjadi #047857 (darker still)
  - Tidak ada transformasi scale atau translate yang dapat menyebabkan layout flicker
  - Icon keranjang belanja dengan ukuran 1.25rem dan warna putih

### 3. Pertimbangan Responsif
- Tombol tetap terlihat baik pada berbagai ukuran layar
- Padding dan tipografi tetap proporsional
- Tidak ada perubahan layout yang dapat menyebabkan flicker
