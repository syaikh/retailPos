# Plan: Implementasi WebSocket dengan Keamanan JWT

## Goal
Mengganti implementasi WebSocket yang ada dengan versi aman menggunakan JWT validation, rate limiting, dan fitur keamanan lainnya. Mengimplementasikan pendekatan "tanpa mutex" (pure channel-based).

## Files yang Perlu Diedit

### Step 1: Update `internal/ws/hub.go`
Replace seluruh file dengan implementasi aman:

**A. Concurrency Design (Tanpa Mutex):**
- Hub.Run() sebagai single goroutine yang mengelola state rooms
- Kommunikasi via channels: register, unregister, broadcast, stats
- Atomic untuk counter sederhana (clientCount)
- Tidak ada mutex untuk critical path

**B. Security Features:**
- JWT validation (token dari query/header)
- Rate limiting (100 msg/detik per client)
- Connection limits (100/client/store, 1000 total)
- Origin check (whitelist, aktif di production)
- Event whitelist validation
- Graceful close dengan proper close message

**Event Types untuk Whitelist:**
- `sale.created` (dipakai sales_service)
- `stock.updated` (dipakai sales_service)

### Step 2: Update `internal/service/sales_service.go`
Update pemanggilan Broadcast karena signature berubah:
- baru: `Broadcast(storeID, eventType, payload) error`
- lama: `Broadcast(eventType, payload)` (no return, no storeID)

```go
// Sebelum:
s.hub.Broadcast("sale_created", sale)

// Sesudah:
// Note: ignore error karena ini fire-and-forget di service layer
_ = s.hub.Broadcast("", "sale.created", sale)
```

### Step 3: Test Compatibility
- Build project untuk memastikan compile
- Jika ada error lain, fix sesuai kebutuhan

## Architecture (Tanpa Mutex)

```
┌─────────────────────────────────────────────────────────────┐
│                     Hub.Run() - SINGLE GOROUTINE             │
│  - Manage rooms map (only one goroutine modifies state)     │
│  - Handle: register, unregister, broadcast, stats channels  │
│  - NO MUTEX NEEDED - single writer principle                │
└─────────────────────────────────────────────────────────────┘
         ▲              ▲              ▲              ▲
    register      unregister      broadcast        stats
         │              │              │              │
         ▼              ▼              ▼              ▼
    ┌─────────┐   ┌─────────┐   ┌──────────┐  ┌──────────┐
    │ Client  │   │ Client  │   │  Event   │  │  Stats   │
    │register │   │unregister│  │ channel  │  │ request  │
    └─────────┘   └─────────┘   └──────────┘  └──────────┘
```
