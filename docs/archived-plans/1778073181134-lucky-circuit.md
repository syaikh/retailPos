# Plan: Enhance Inventory Page Product Name Column with Barcode/SKU Copy Feature

## Objective
Modify the Inventory page table to display barcode and SKU information below the product name in a smaller font, with copy icons that allow users to copy these values to clipboard and show a toast confirmation.

## Current State
- Inventory page table has columns: SKU, Name, Category, Barcode, Price, Stock, Actions
- User wants to reduce visual clutter by moving barcode and SKU details under the product name
- Keep all information accessible while maintaining clean table layout

## Changes Required

### 1. File to Modify
`web/src/lib/pages/InventoryPage.svelte`

### 2. Specific Modifications

#### In the table body (`{#each products as product}`):
- Replace current product name cell (`<td class="p-4">{product.name}</td>`) with:
```svelte
<td class="p-4">
  <!-- Product name (normal size) -->
  <div class="font-medium">{product.name}</div>
  
  <!-- Barcode and SKU details (smaller font) -->
  <div class="flex items-baseline gap-2 mt-1 text-xs text-text-muted">
    <!-- Barcode with copy button -->
    <span class="flex items-center gap-1">
      {product.barcode}
      <button
        class="p-0.5 hover:text-primary transition-colors"
        title="Salin barcode"
        onclick={() => {
          navigator.clipboard.writeText(product.barcode).then(() => {
            toast.show(`Barcode copied: ${product.barcode}`, { 
              duration: 2000, 
              position: 'top-right' 
            });
          });
        }}
      >
        <Copy size={14} class="text-text-muted hover:text-primary" />
      </button>
    </span>
    
    <!-- SKU with copy button -->
    <span class="flex items-center gap-1 ml-4">
      {product.sku}
      <button
        class="p-0.5 hover:text-primary transition-colors"
        title="Salin SKU"
        onclick={() => {
          navigator.clipboard.writeText(product.sku).then(() => {
            toast.show(`SKU copied: ${product.sku}`, { 
              duration: 2000, 
              position: 'top-right' 
            });
          });
        }}
      >
        <Copy size={14} class="text-text-muted hover:text-primary" />
      </button>
    </span>
  </div>
</td>
```

#### Required Imports
- Ensure `Copy` icon is imported from `lucide-svelte` (check if already imported in script section)
- Toast store is already imported: `import { toast } from '$lib/stores/toast';`

### 3. Styling Considerations
- Use existing text utilities: `text-xs`, `text-text-muted`
- Maintain spacing with `mt-1`, `gap-2`, `ml-4`
- Use `flex items-baseline` for proper alignment
- Hover effects on buttons: `hover:text-primary transition-colors`
- Keep copy icon size consistent: `size={14}`

### 4. Behavior
- Clicking copy icon copies the respective value (barcode or SKU) to clipboard
- Shows a toast notification at top-right for 2 seconds with message:
  - "Barcode copied: [value]" for barcode copy
  - "SKU copied: [value]" for SKU copy
- No changes to existing table columns count (still 6 columns: SKU, Name, Category, Price, Stock, Actions)
- All existing functionality (sorting, filtering, modal actions) remains unchanged

### 5. Implementation Notes
- This change only affects the product name cell display
- No changes needed to API or backend since barcode and SKU are already fetched
- Toast positioning uses existing toast mechanism from the application
- Maintains accessibility by keeping original values in DOM (just visually reorganized)

### 6. Fallback Consideration
- If clipboard API fails (rare in modern browsers), consider adding try/catch with fallback toast
- However, given the internal nature of this POS system, clipboard API is reliable

## Expected Outcome
- Cleaner table appearance with reduced column visual width
- All product information remains accessible
- Enhanced user experience with one-click copying of identifiers
- No theme changes required - uses existing styling utilities
