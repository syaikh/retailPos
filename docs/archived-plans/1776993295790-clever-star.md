# Plan: Fix POS Cart Scrolling and Styling Issues

## Problem Analysis

1. **Cart items not scrollable**: The `.cart-area` container has `overflow: hidden` which prevents scrolling when cart has many items.
2. **Payment method selection too tall**: Cash/Card buttons use vertical layout with large padding (16px), wasting space.
3. **Total font too large**: `.total-amount` uses `1.75rem` font-size, taking too much space.
4. **Payment button styling**: Needs improved font/appearance.

**File**: `web/src/routes/(app)/pos/+page.svelte`
